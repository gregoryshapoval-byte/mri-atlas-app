Два независимых блока: ТФХК и остальные связки. ≈ — приблизительная область, не выделенные волокна. Поиск находит структуры во всех сериях текущего набора; каталог показывает также элементы без отдельной метки.

Один палец: листание срезов, включая увеличенный вид. Два пальца: масштаб и перемещение. ⛶ — весь экран. «☰ Анатомия» — группы с изображениями, выбор отдельных структур и поиск.

Источник и особенности

Из пользовательского архива IMAIOS e-Anatomy перенесены оригинальные координаты каждой точки, русские названия, группы и доступные цветные слои. Все исходные метки доступны через меню; это не независимая проверка каждой анатомической структуры.

Это JPEG, не DICOM. 3D-разделы содержат готовые ракурсы, а не объём для свободного вращения. Два окна связываются только для T1/PD одной исходной серии; разные плоскости не синхронизируются. Поиск работает в выбранной серии. При большом числе подписей используй кнопку «ещё» или выключи ненужные группы.
