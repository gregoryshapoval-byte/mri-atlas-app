    ЦАА: Boston 2.0 · клиника, МР-категории и исключения

    Общие условия: возраст ≥50 лет; спонтанное внутримозговое кровоизлияние, транзиторные фокальные неврологические эпизоды либо когнитивное снижение / деменция; отсутствие иной причины геморрагических очагов и любых глубоких ВМК / микрокровоизлияний.

    КатегорияМР-условия при выполнении общих условий
    Вероятная · probable≥2 строго лобарных геморрагических очага в любой комбинации: ВМК, микрокровоизлияния, отдельные фокусы cSS / конвекситальной САК; ИЛИ 1 строго лобарный геморрагический очаг + ≥1 из двух специальных маркеров белого вещества ниже.
    Возможная · possible1 строго лобарный геморрагический очаг ИЛИ 1 специальный маркер белого вещества; критерии вероятной категории не выполнены.

    Специальные маркеры: выраженные ПВП полуовального центра: >20 в одном полушарии на аксиальном срезе максимальной выраженности; либо multispot WMH: >10 мелких округлых / овальных T2/FLAIR-очагов двусторонне в подкорковом белом веществе. Любой высокий Fazekas не заменяет эти маркеры.

    Мозжечковая кровь не считается ни лобарной, ни глубокой для Boston 2.0. cSS / САК в одном месте не считать дважды; оценивать отдельные фокусы, а не каждую затронутую борозду. Исключать травму, геморрагическую трансформацию инфаркта, АВМ, геморрагическую опухоль, васкулит и другие причины cSS / САК.

    Достоверная ЦАА и вероятная ЦАА с патологическим подтверждением требуют ткани и здесь по МРТ не присваиваются. МР-категории не равны гистологическому диагнозу; смешанная кровь не исключает сосуществующую ЦАА. Для бессимптомных находок и пациентов <50 лет эти категории автоматически не применять.

    Качество и сравнение

    Сопоставлять поле, TE, толщину, SWI против GRE и обработку. Более чувствительная серия может показать больше старых микрокровоизлияний без истинного прогрессирования. Без susceptibility-серии нельзя уверенно отрицать кровь / cSS.

    Шкала Fazekas не включает лакуны, ПВП и кровь. Суммарный SVD score имеет несколько версий; здесь не рассчитывается и не заменяет описание каждого маркера.

    Источники и границы модуля

    Проверено21.10.2026. Взрослая МР-характеристика преимущественно спорадической болезни мелких сосудов. Не полный лечебный, генетический, детский, CAA-ri или ARIA-алгоритм. МРТ не определяет причину всех симптомов и не назначает антитромботическую терапию.
