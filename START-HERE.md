## Работа без повторной загрузки всего проекта

Использовать один коммит с изменёнными путями. Для локального Git: tools/push_changes.py; при отсутствии Git-аутентификации — GitHub create_tree с base_tree_sha, inline content для нескольких небольших текстовых файлов, create_commit и update_ref с expected_sha. Не пересылать бинарные данные/base64 через обсуждение. Большие снимки передавать байтовым каналом, а не текстом модели.

Не читать рекурсивно весь репозиторий, историю отчётов или все assets при каждой задаче. Читать нужные файлы диапазонами; результаты хранить локально, в ответе — итог и ошибки. После законченной задачи обновлять этот файл коротким текущим состоянием; подробности — отдельный review-файл.

Очистка загрузок не является способом восстановления лимита обсуждения. При read-only продолжить в новом чате с URL репозитория и этим файлом.
