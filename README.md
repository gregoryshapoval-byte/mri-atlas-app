# MRIAtlas 2.41

Личный офлайн-атлас МРТ и КТ для Android 8.0+. Актуальный исходный код — ветка `main`, versionCode 141.

Включены все разделы версии 2.40 и галерея из 12 реальных МР-примеров эндометриоза с разбором, увеличением и локальными изображениями. Каталог и прежние анатомические снимки сохранены.
