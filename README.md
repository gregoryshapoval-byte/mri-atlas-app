# MRIAtlas 2.42

Личный офлайн-атлас МРТ и КТ для Android 8.0+. Актуальный исходный код — ветка `main`, versionCode 142.

Включены все прежние разделы, 12 реальных МР-примеров эндометриоза и 20 иллюстраций рака прямой кишки: стадирование, MRF/EMVI, узлы, муцин и ответ на лечение. Снимки работают офлайн; есть разборы, поиск и увеличение.

APK подписывается сохранённым ключом с сертификатом `cb7d43e1…3624fe`, совпадающим с 2.40. Автоматические сборки при обычных изменениях выключены; основной build workflow запускается вручную.

Все медицинские материалы учебные; отдельные иллюстрации не заменяют полное исследование. Авторство и лицензии опубликованных снимков приведены внутри модуля.
