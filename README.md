# МРТ Атлас · Плечо — Android 1.0

Офлайн-приложение для изучения топографии сумок плечевого сустава.
Android 8.0+; современный Android System WebView с поддержкой WebGL2 и import maps.
Модель и Three.js включены в приложение. Нет аккаунта, сервера, рекламы,
трекеров, разрешений на интернет, камеру или файлы. Ссылки на медицинские
источники открываются отдельным браузером и требуют интернет-соединения.

## Управление
Один палец — вращение, два — масштаб и перемещение.
Ниже модели расположены список структур, слои и сечения.
В горизонтальном положении настройки располагаются сбоку.
Кнопка назад закрывает справку, затем приложение.

## Ограничения
Учебная вручную построенная топографическая геометрия, не сегментация пациента.
Нельзя использовать для измерений или планирования вмешательства.
Редкие сумки представлены условно; подробнее — в карточках модели.

## Сборка в Android Studio
Откройте эту папку как проект. Используются JDK 17, Android SDK 35,
Android Gradle Plugin 8.7.3, совместимый Gradle 8.9.
Установите SDK через SDK Manager, выполните синхронизацию Gradle и
Build > Build App Bundle(s) / APK(s) > Build APK(s).
Результат: app/build/outputs/apk/debug/app-debug.apk.

## Сборка без Gradle
Скрипт build-apk.sh использует Android SDK platform 35, Build Tools 35.0.0,
JDK 17, Python 3, unzip. Передайте ANDROID_SDK_ROOT.
Ключ подписи хранится отдельно в каталоге SIGNING_DIR; не удаляйте его,
если нужны последующие обновления поверх установленного приложения.
В раннем приватном исходном архиве использовался персональный ключ.
В текущем git-репозитории ключ отсутствует; подробности в CONTINUE.md.

## 1.6 — Главное меню, надколенник и миомы FIGO
- Главная → область → схема. Колено (5), плечо (2), малый таз (1). ТБС явно помечен как пока не заполненный раздел.
- Пателлофеморальный сустав: шесть примеров, независимые настройки наклона, смещения, высоты и уплощения борозды. Аксиальное сечение пересекает реальные треугольники модели. Нет расчёта клинических индексов, контактной механики и траектории движения.
- Матка: грушевидное тело, перешеек, шейка, полость, оболочки, ориентиры придатков. Типы FIGO 0–8 и гибридный 2–5. Разрез / целая матка / прозрачность. Геометрия узла вычитается из поверхности стенки шейдером. Контрольная 2D-схема и шаблоны описаний.
- Геометрия условная. Полость расширена в примерах 0–2 и 2–5; оболочки утолщены. Непрерывная наружная оболочка не является картой перитонеального покрытия.
- Тесты: node tests/anatomy.mjs (Node.js 24). Проверяют границы узлов, отсутствие выхода типов 3/4 в полость и за наружную поверхность, положение типа 0, контактные зазоры надколенника и сечение при alta. PNG проверялись как внутренние геометрические проекции; полноценная Android/WebGL-проверка новой версии не проводилась.

## 1.7 — Лучезапястный сустав
Главное меню → Лучезапястный сустав → Связки / Сухожилия / TFCC. Всего 11 схем.
- Связки: SL и LT с тремя компонентами; основные ладонные и тыльные наружные связки; UL и UT.
- Сухожилия: шесть каналов разгибателей; 9 сухожилий сгибателей, FCR в отдельном канале, FCU и PL вне карпального канала; срединный нерв и удерживатели. Аксиальная карта показывает уровень дистального предплечья, не карпальный канал.
- TFCC: норма, Palmer 1A–1D и 2A–2E. Дефекты являются отверстиями/разрывами геометрии. При 1B можно отдельно показать фовеальные и стилоидные волокна; при 1C — дистальное повреждение UL/UT; при 2D/2E — дефект мембранозной LT. Хондромаляция/артроз обозначены условными цветными поверхностями, не картами МР-сигнала.
- Форма костей и комплекс TFCC обобщены. Контрольная модель не рассчитывает стабильность ДЛЛС, нагрузку или динамику сухожилий.
- Проверка: node tests/wrist.mjs; 10 состояний Palmer, непрерывность при изнашивании и отверстия при перфорации, состав каналов, конечные векторы кривых, 11 маршрутов меню. Геометрические проекции осмотрены. Новая версия не запускалась в Android/WebView в среде сборки.

## 1.10 — жесты и меню анатомии
Один палец вниз/вверх непрерывно листает срезы (30 CSS px на срез по умолчанию) при любом масштабе. Два пальца одновременно меняют масштаб вокруг центра жеста и перемещают область. После отпускания одного пальца остаток жеста не листает. Масштаб, смещение и поворот сохраняются при смене кадра. SVG имеет постоянные координаты изображения, а плотные подписи адаптируются к фиксированному окну.
Выдвижной dialog: анатомические группы с иконками, вложенные группы, отдельные структуры, поиск, маркеры, подписи, подписи в видимой области, цветные маски, поворот/отражение/сброс, режим одного пальца, чувствительность, яркость/контраст. Перекрёстные ссылки и новые языки не добавлялись. Использованы существующие координаты и группы без изменений медицинских данных. Настройки разметки сохраняются локально.
Изучена структура APK 6.0.4: viewer_drawer_filter, parent_filter, onefingertype, transforms, switch и segmented_control. Воспроизведён нужный рабочий сценарий собственным кодом. Проверены жесты модульными тестами и управление меню в happy-dom, запуск на реальном Android не выполнен.
