# MRIAtlas 2.44

Личный офлайн-атлас МРТ и КТ для Android 8.0+. Актуальный исходный код — ветка `main`, versionCode 144.

Включены все прежние разделы, 12 реальных МР-примеров эндометриоза и 20 иллюстраций рака прямой кишки и 24 иллюстрации образований печени: кисты, гемангиомы, ФНГ, аденомы, ГЦР, холангиокарцинома, метастазы и диагностические ловушки. Снимки работают офлайн; есть разборы, поиск и увеличение.

В галереях каждый кадр показан отдельно, вертикально на ширину телефона; сохранены подписи, увеличение панели и доступ к исходной композиции. Проверка: [вертикальные панели 2.44](review/panels-2.44.md).

Все медицинские материалы учебные; отдельные иллюстрации не заменяют полное исследование. Авторство и лицензии опубликованных снимков приведены внутри модуля.
