## Архитектура и активные слои
Это существующее Android Activity + WebView-приложение, не новый проект. Локальные assets обслуживаются через appassets.androidplatform.net. Навигация трёхуровневая; источник правды — текущие маршруты/манифесты, не старый список в переписке. Доступно 11 МРТ-модулей, наряду с прежними учебными 3D-разделами.

## Восстановление базы и связь меток
Полная процедура и ограничения: **`SOURCE_RECOVERY.md`**, реализация **`tools/recover_source_database.py`**. Она уже сохранена в git, не зависит от истории чата.

Исходник — пользовательский `net.imaios.eanatomy.zip`, внутри Android Backup `net.imaios.eanatomy.ab`. APK для восстановления берётся из `apps/net.imaios.eanatomy/a/base.apk` внутри backup, база из `apps/net.imaios.eanatomy/db/eAnatomy.db`, медиа из `apps/net.imaios.eanatomy/ef/v5/.files/{module}.zip`. Не подменять вложенный APK отдельной версией приложения.

Заголовок AB: ANDROID BACKUP / 1 / 1 / none, затем zlib TAR. В архиве нестандартные TAR checksum: скрипт использует ограниченное чтение 512-байтных заголовков и точный whitelist, а не небезопасную массовую распаковку.

База SQLCipher compatibility 3. В classes.dex вложенного APK скрипт извлекает const-string из класса `Leanatomy/library/a/a;`, метода `b()Ljava/lang/String;`: Base64 → UTF-8 → XOR 128 по символам → обратный порядок. Ключ только в памяти, не в логах/документации. Порядок: PRAGMA key, cipher_compatibility=3, проверка sqlite_master, экспорт через sqlcipher_export. Если версия APK не совпадает, остановиться, не угадывать.

Сопоставление: module.imaios_code → series → contrast/slice; номер в имени — slice.sort_order, не индекс массива. JPEG hash имени = SHA256("{module}#{contrast.imaios_code}#images-{slice.sort_order:04}.jpg"), PNG = SHA256("{module}#{filter.layer}#images-{slice.sort_order:04}.png"). point.slice_id/structure_id связываются с slice/structure; русские переводы lang_id=10, английский резерв lang_id=2. x_pixel/y_pixel относятся к реальным JPEG; размеры брать из изображения, не series.canvas_width/height. Сохранять sourceSeries/sourceFrame/annotation/original/SHA/width/height.

Базовый запуск в новом временном каталоге:
```sh
python3 -m pip install androguard sqlcipher3-binary pillow
python3 tools/recover_source_database.py /path/net.imaios.eanatomy.zip /tmp/atlas-source-new
```
Это восстанавливает точный whitelist исходных трёх модулей, не все медиа. Перед импортом изучить подходящий скрипт:
- `tools/import_source_modules.py` — восстановленные ранние модули/таз;
- `tools/import_additional_mri.py` — плечо/голеностоп-предплюсна;
- `tools/import_mri142.py` — колено/лицо-шея/ТБС/позвоночник.
Дополнительные ZIP извлекать отдельным точным whitelist. Не расширять импорт догадками. Не запускать бездумно повторный импорт поверх ручных исправлений. В частности, сырой переимпорт мозга сотрёт исправления ВСА.

Архив может отсутствовать в новом локальном workspace. Для уже импортированных модулей он не требуется: JSON, изображения/упакованные ресурсы и overlays сохранены в репозитории. Если нужен повторный импорт, сначала найти известный пользовательский архив, а не просить загрузить его заново без проверки доступных файлов.

## APK и ключ
Actions **Build Android APK** создаёт `MRIAtlas-1.49-unsigned`; это не готовый устанавливаемый подписанный релиз. Ключ в репозитории не хранится. `build-apk.sh` требует прежний atlas.jks в SIGNING_DIR; при отсутствии останавливается. Не генерировать новый debug/release key для «продолжения»: обновление поверх установленной версии перестанет работать. Подтверждать сертификат по SHA выше, затем apksigner verify и целостность/версию/упакованные assets. Секреты не публиковать.

Локальные рабочие каталоги и ключ могли быть очищены обслуживанием среды. Наличие готового APK не означает наличие приватного ключа: APK не позволяет восстановить ключ. Перед следующим выпуском проверить доступность оригинального ключа в разрешённых приватных исходных файлах. При его отсутствии честно указать блокер подписания, сохранив сделанную работу и unsigned CI-артефакт. Предыдущий готовый подписанный1.49 повторно собирать только ради переноса чата не требуется.
