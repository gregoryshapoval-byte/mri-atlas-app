# Подпись актуального MRI Atlas

Начиная с 1.83 используется сохранённая владельцем публичная тестовая идентичность.
Фактический APK 2.40 и выпуск 2.41 имеют сертификат SHA256:
`cb7d43e1eb8ff4c1eee663e918b5413b70fb9d6f8221790075f83c7e153624fe`.

Постоянный резервный архив находится в этом GitHub-репозитории:
Release `atlas-1.83-personal-backup`, asset `MRIAtlas-test-signing-key.zip`.
SHA256 архива: `21e95c8f3b3b57579f8ad930e5dd011a7800efccc00750b003d70a5a9d9c87c6`.
В архиве `atlas.keystore`, `certificate.der`, `certificate.sha256`, `README.txt`.
Alias и пароли — `atlas` / `android`.

Восстановление из корня проекта:

```sh
python3 tools/restore_signing_key.py
ANDROID_SDK_ROOT=/path/android-sdk bash build-apk.sh
```

Скрипт сохраняет ключ вне репозитория в `../atlas-signing/atlas.keystore`, проверяет архив и сертификат. build-apk.sh также проверяет сертификат перед подписью. При изменённом SIGNING_DIR передайте тот же путь скрипту восстановления аргументом.

Не создавать новый ключ. Не считать отсутствие локального keystore потерей ключа: сначала восстановить постоянную копию. Не коммитить извлечённые ключи.

Исторический ключ из `MRIAtlas-1.18-project.zip` → `atlas-signing/atlas.jks` имеет сертификат `9cc66233…cec14`. Он не совпадает с 2.40; старые инструкции о нём относятся к выпускам до перехода на публичную тестовую подпись. Для выбора ключа всегда сверять фактический предыдущий APK.
