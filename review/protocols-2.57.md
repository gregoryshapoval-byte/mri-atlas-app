# MRIAtlas 2.57 — единый формат существующих протоколов

Новых клинических модулей и маршрутов нет. Охвачены все найденные действующие вкладки сканирования: 70 протоколов на 63 HTML-страницах, включая восемь отдельных тем brain-oncology247. Перечень — protocol257-data.js. Это унификация имеющихся протоколов, а не заявление о наличии протокола на каждой из 85 страниц клинического каталога.

Пять блоков в одном порядке: подготовка / покрытие; основные серии; дополнительные серии по задаче; контрастирование; качество / ограничения. Название вкладки — «Протокол МРТ». Карточки одинаково подписывают поля серий, покрытия, параметров и условий. Дополнительные назначения не становятся обязательными; смешанные строки сохраняют исходные условия. В блоке контраста явно указано, что само наличие блока не является показанием к введению. Для неполного исследования предусмотрена формулировка ограничения вместо отрицательного признака.

398 исходных строк / карточек читаются из действующего DOM после загрузки раздела, а не из дублированного медицинского справочника. Явная карта названий и групп сверяется до преобразования; при несовпадении исходный протокол остаётся доступным без перестановки строк. MutationObserver прекращает работу после успешной нормализации. Вход protocol257=1 открывает существующую вкладку, включая маршруты с topic.

Исходные таблицы и все примечания остаются в раскрываемом блоке «Технические таблицы и дополнительные пояснения». Оригинальные DOM-узлы с их ID и обработчиками не удаляются. GE 1,5 Т для прямой кишки явно остаётся стартовым примером; вводное уточнение первичной диагностики РС сохранено над новым форматом. Параметры, единицы, показания к сериям, опубликованные источники и диагностические пороги не переписывались. Словарь ориентаций и FS / FOV / gap общий.

Генератор поиска пропускает служебную карту протоколов, чтобы её названия не попадали во все разделы. 721 поисковая запись, 85 модулей, прежние прямые ссылки сохранены. Изображения, исходные метки и layouts не менялись. HTML каждой затронутой страницы отличается от базы только подключением одного JS и одного CSS; это проверяется tests/protocol257.mjs.

Проверки: protocol257; браузер — 70 протоколов × 4 размера (320 / 393 / 852 / 1280), все пять блоков, точное сохранение каждой исходной ячейки / абзаца в 398 карточках, раскрытие старых таблиц, доступность вкладки с клавиатуры, отсутствие JS-ошибок, 404, внешних запросов и переполнения. Проверены скриншоты печени, прямой кишки, РС; сохранены также орбиты и простата. Регрессии: review256, navigation238, clinical254, clinical255, head-neck251, prostate187, panel-layouts244, актуальность поиска / версии, git diff --check.

Обновлённый формат не является независимой врачебной валидацией медицинского содержания и не задаёт универсальных пресетов сканера. Рекомендации / технические значения исходных страниц сохранены. Подписанный APK 157/2.57: прежний сертификат, v2/v3, целостность ZIP и все runtime-assets проверяются при выпуске; параметры в protocol257-build-info.json. Физический Android не проверялся. Публикация GitHub Release в задаче не выполняется.
