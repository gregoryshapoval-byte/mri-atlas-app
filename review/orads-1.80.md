# MRI Atlas 1.80 · O-RADS MRI

Добавлен клинический модуль «Малый таз → Образования придатков · O-RADS MRI».
Оценка одного образования по морфологии и усилению; отдельные ветви физиологических находок, эндометриом, дермоидов, dark T2/dark DWI ткани, труб и параовариальных кист. DCE и ранняя нединамическая фаза разделены. Неполные данные не превращаются в отрицательные признаки. Без пригодного миометрия не выполняется автоматическое разграничение 4/5 по кривой с плато.

Памятка, схематические кривые усиления, технические ориентиры ACR с названиями семейств серий GE, редактируемый черновик с защитой ручных правок. Патологические МР-примеры не добавлены. Система предназначена для среднего риска без острой симптоматики; решение подтверждает врач.
