# MRI Atlas 1.84 — рассеянный склероз

Основа: work/orads-simplify-1-83 / af1f798f677af58e7fd883acb41df38784881bca (1.83, включая упрощение O-RADS). Продолжение на той же актуальной ветке; main 1.82 не использован.

Новый маршрут: Головной мозг → Рассеянный склероз. Пять вкладок: признаки, критерии, отличия, сканирование, заключение. Шесть интерактивных авторских SVG-схем локализаций, увеличение; CVS/PRL раскрываются отдельно. Схемы условные, не МР-срезы. Мозолистое тело явно не отдельная шестая топография DIS. DIS/DIT и активность разделены. Шаблоны требуют ручного заполнения; автоматического диагноза нет.

По дополнительной просьбе пользователя включены требования к МРТ: мозг, весь спинной мозг, орбиты; пространственное разрешение, толщина, контраст/задержка, контроль, CVS/PRL. Для GE 1.5 Т не выдуманы TR/TE/TI и точное время без консоли.

Источники: Montalban et al. McDonald 2024 (Lancet Neurology 2025; PMID40975101); Barkhof et al. MAGNIMS-CMSC-NAIMS2024 (2025; PMID40975102); Wattjes et al.2021 (PMID34139157); Filippi et al.2019 (PMID31209474); официальный ECTRIMS slide deck2025. Ссылки встроены, модуль работает офлайн.

Среда локального исполнения недоступна (No usable execution environment is available). Подготовка через GitHub API, синтаксис JS проверен JavaScript parser в code mode; браузер/Android выполняются в отдельном CI только для этого запроса. Тест tests/browser-ms184.mjs: 4 экрана, 6 схем, 5 вкладок, увеличение/Escape, отсутствие overflow, clipboard/fallback, клавиатура, маршрут и отсутствие внешних запросов. Статус CI на момент исходного коммита: ещё не выполнен, успех не заявляется.

Все прежние MRI/метки/слои сохраняются; workflow сравнивает blobs assets с базовым commit и payload APK после подписи. Подпись: тот же намеренно публичный тестовый ключ из постоянной копии1.83, с проверкой SHA256 архива/сертификата; новый ключ не генерируется. Готовность APK, CI и ссылка фиксируются после выполнения. Физический Android и независимая врачебная верификация не проведены.
