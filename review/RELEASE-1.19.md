# MRIAtlas 1.19

## Лучезапястный сустав — МРТ

- Добавлен офлайн-модуль `wrist-mri.html`.
- 148 МРТ-срезов из пользовательского архива IMAIOS e-Anatomy:
  - PD-SPIR AX — 44;
  - PD-SPIR COR — 30;
  - T1 AX — 24;
  - T1 COR — 20;
  - T1 SAG — 30.
- Добавлен 61 готовый 3D-ракурс костей запястья из того же набора.
- Листание одним пальцем, pinch-to-zoom, яркость/контраст, полный экран.
- Два окна для сравнения; синхронизация выполняется по относительному положению в серии, чтобы серии разной длины не расходились.
- Быстрые переходы к интерактивным модулям связок, сухожилий и TFCC Palmer.
- Раздел ЛЗС в меню расширен до четырёх модулей.

## Проверка источника

Изображения перенесены без интерполяции из `wrist-mri-3d.zip`. Это JPEG, не DICOM. Названия контрастов и разбиение на плоскости соответствуют структуре исходного набора; параметры сканирования в JPEG отсутствуют.
