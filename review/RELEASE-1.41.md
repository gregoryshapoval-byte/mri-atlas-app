# MRI Atlas 1.41

- Основа — 1.4 на базе 1.30. Все прежние МРТ-данные и ручные правки координат сохранены.
- Женский таз подключён к общему интерфейсу с исправлением исходных настроек групп.
- Плечо: 230 кадров T1/PD-SPIR, 3151 исходная точка. Предплюсна/голеностопный сустав: 284 кадра, 6653 точки. Три плоскости в обоих модулях. Схемы и остальные области сохранены.
- Просмотр на всю высоту окна по умолчанию. Компактные серии/управление, справка в «Информации», слайдер и сброс масштаба доступны всегда. Два окна и отдельный полный экран сохранены.
- Быстрое переключение: подписи, только точки с карточкой по касанию, без меток. Последний режим показывает чистый JPEG без цветных слоёв.
- Единая палитра по анатомическим категориям; исходный цвет в JSON сохранён. Ориентировочные точки контурные с пунктиром.
- Подписи одинакового экранного размера; две боковые колонки, переносы с учётом ширины, расстояния с учётом высоты текста, страницы при переполнении. Скрываются точки вне кадра/видимой области.
- Быстрое листание одним пальцем, масштаб/перемещение двумя, двойное касание переключает увеличение и исходный масштаб.
- Проверки данных, меню и режимов всех семи МРТ-модулей. Физическое Android-устройство для проверки недоступно.
