# 1.64 — ускорение свайпа и непрерывное листание зон

По умолчанию один кадр требует10 CSS-px вертикального движения вместо18: примерно1,8 раза быстрее. В «Анатомия → Вид и жесты» доступны30/18/10/6px — медленно, обычно, быстро, очень быстро. Выбор сохраняется в настройках модуля, включая перестройку двух окон и перезапуск страницы. Сброс возвращает10px. На коротком6px-свайпе кадр уже может смениться, поэтому такое движение больше не считается касанием точки или частью двойного касания.

`viewer-series-flow.js` задаёт только две явные цепочки:

- Верхняя конечность: плечевой пояс → плечо → локоть → предплечье → запястье → кисть,194 кадра.
- Нижняя конечность: ягодичная область → бедро → колено → голень → предплюсна → стопа,277 кадров.

Порядок проверяется по последовательным исходным sourceFrame. При неполном/непоследовательном наборе автопереход отключается. Остальные MRI-серии являются плоскостями/контрастами или3D-ракурсами; они не объединяются. Никакая DICOM-геометрия не восстанавливается и пространственного сшивания нет.

На границе зоны остаток движения переносится в следующую/предыдущую зону. За один непрерывный жест можно пройти несколько зон, включая движение назад. Кнопки, клавиатура и колесо используют тот же переход. Ползунок остаётся точным переходом внутри текущей зоны; название и локальный счётчик обновляются автоматически. В абсолютном начале/конце цепочки остановка, без циклического возврата.

При автоматическом переходе сохраняются режим меток, группы, скорость, яркость/контраст, поворот и отражения. Относительный масштаб сохраняется в пределах прежнего ограничения1…5; новая зона центрируется по своей рамке fit. Выделенная анатомическая структура сбрасывается. Связанные окна переходят вместе; синхронизация обычных T1/PD той же исходной серии сохранена. Соседний кадр предварительно декодируется и через границу зоны. LatestFrame по-прежнему защищает показ от запоздалых загрузок: точки рисуются по фактически отображаемому кадру.

Изменены только runtime управления, справочный текст конечностей и версия. Исходные MRI, координаты, метки, overlays, иконки1.63, женский таз1.62 и свищевые модели1.61 не изменены. Контрольные суммы в JSON-отчёте.
