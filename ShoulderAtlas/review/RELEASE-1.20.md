# MRIAtlas 1.20

Добавлен офлайн-модуль «Локтевой сустав» из пользовательского архива IMAIOS e-Anatomy.

- 260 МРТ-срезов: PD-FS и T1.
- AX: по 65 срезов для каждого контраста, сохранены двумя исходными блоками 35 + 30.
- COR: по 32 среза.
- SAG: по 33 среза.
- 61 готовый 3D-ракурс костей локтевого сустава.
- Листание жестом/ползунком, pinch-to-zoom, яркость/контраст, полноэкранный режим.
- Режим двух окон с синхронизацией по относительному положению в серии.
- Добавлены карточки локтевого сустава в главное меню и меню области.
