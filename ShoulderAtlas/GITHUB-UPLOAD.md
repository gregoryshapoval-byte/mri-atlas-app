# Как загрузить проект в GitHub с телефона

Проект уже подготовлен для репозитория `mri-atlas-app`.

## Важно

Не коммитьте файлы `*.jks`, `*.keystore` и каталог `atlas-signing/`.
Они исключены через `.gitignore`.

## После загрузки

В репозитории появится GitHub Actions workflow **Build Android APK**.
Он запускается автоматически при push в `main` и вручную из вкладки **Actions**.
Готовый APK будет находиться в артефакте `MRIAtlas-1.23-apk`.

Workflow использует временный ключ подписи, если постоянный ключ не предоставлен.
Поэтому APK из разных запусков может потребовать удалить предыдущую установленную
сборку перед установкой новой. Для нормальных обновлений поверх установленного APK
позже нужно подключить постоянный signing key через GitHub Secrets.
