# Сборка и выпуск MRIAtlas

Актуальная версия2.41/versionCode141, веткаmain. Подробности состояния — CONTINUE.md. Android SDK35/build-tools35.0.0, JDK17.

## Локальная сборка

```sh
python3 tools/restore_signing_key.py
ANDROID_SDK_ROOT=/path/android-sdk bash build-apk.sh
```

Результат — build/MRIAtlas-2.41-restored.apk. Для проверки без ключа передать UNSIGNED_ONLY=1; такой APK не является устанавливаемым подписанным выпуском. Подпись и постоянная копия ключа — SIGNING.md.

build-apk.sh сначала восстанавливает точные локальные ресурсы из source-assets. Ключ хранится вне репозитория. Проверяются текущий сертификат и подписьAPK. Перед выпуском сверить package,versionCode/versionName,ZIP и assets.

## GitHub Actions

Build Android APK запускается вручную. Обычные push не должны автоматически запускать полную сборку и все браузерные проверки.

Consolidate current MRI Atlas — обслуживающая процедура сохранения актуального релиза и уборки старых веток/релизов. Перед удалением проверяет достижимость зафиксированных heads в main, сохранность копии ключа и исходного архива, наличие проверенного APK актуального релиза. Перечень целей ограничен реестром review/github-cleanup-2026-10-24.json. Не использовать её для удаления новой независимой работы.
